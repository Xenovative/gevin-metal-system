# 貴金屬加工廠 — 發票與倉存系統

為貴金屬加工廠銷售人員設計的逐步填寫系統，自動生成 Excel 發票並記錄金屬進出倉。

## 功能

### 發票系統
- 逐步引導填寫：交易性質 → 基本資料 → 貨品 → 備註 → 生成 Excel
- **單號自動產生**：`前綴 + 年份(2位) + 月份(2位) + 流水號(5位)`
  - 銷售 `S`、購入 `P`、兌料 `T`、交收 `D`
  - 例：2026年3月第一張銷售單 → `S260300001`，每月由 `00001` 重新計數
  - 同一前綴共用流水號（所有交收類型共用 D、所有兌料類型共用 T）
- 支援 11 種交易性質，對應 Excel 範本中的不同分頁
- 兌料類交易支援「對換貨品」區塊
- 自動計算両（1 両 = 37.5 克）

### 倉存系統
- 每張發票自動記錄金屬入倉/出倉
- 即時查看庫存結存與進出倉明細

### 報表
- 每日 / 每月 / 每年倉存報表與發票報表（Excel）

## 交易性質對照

| 交易性質 | Excel 分頁 | 單號前綴 | 倉存方向 |
|---------|-----------|---------|---------|
| 銷售 | 銷售(保護) | S | 出倉 |
| 購入 | 購入單(保護) | P | 入倉 |
| 兌料 | 兌料單(保護) | T | 兌換 |
| 兌料(補水) | 兌料單(保護)2 | T | 兌換 |
| 交收收料 | 交收單(保護)收料 | D | 入倉 |
| 交收去料 | 交收單(保護)去料 | D | 出倉 |
| 交收去料(多項) | 交收單(保護)去料 (2) | D | 出倉 |
| 交收回料 | 交收單(保護)回料 | D | 入倉 |
| 交收回料(多項) | 交收單(保護)回料 (2) | D | 入倉 |
| 提純後兌料 | 提純後向客兌料單(保護) | T | 兌換 |
| 提純後兌料(多項) | 提純後向客兌料單(保護) (2) | T | 兌換 |

## 安裝與啟動

```bash
cd ~/Projects/gevin-metal-system
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

瀏覽器開啟 http://localhost:7860
